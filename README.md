# bbtools 共用编码规范

本仓库维护一套可跨仓库复用的中文 C++ 编码与维护规范，覆盖注释、代码风格、技术设计取舍和 Review 要点。

## 文档地图

| 文档 | 内容 |
|---|---|
| [docs/conventions.md](docs/conventions.md) | 共用规范正文（命名、注释、API 设计、技术风格、Review） |

## 使用方式

各仓库在自身文档中接入本规范时，应引用经审查的固定提交及对应文件路径；本仓库内可通过上方链接导航。此链接只用于当前仓库的本地导航，本仓库不自动抓取或同步远端内容。规范以说明原则和理由为主；与各仓库现有约定冲突时，以当前仓库的明确决策为准，不做无关格式迁移。

## 维护原则

- 规则来源须可在私有证据中追溯，不纳入未经验证的助手观察。
- 各仓库的项目差异不在此抹平；通用原则写这里，仓库专属门禁写各仓本地 AGENTS。
- 文档变更须经独立审查后发布，不先推后检。
